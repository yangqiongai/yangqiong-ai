# 泱穹 AI 框架（yangqiong-ai-framework）

泱穹智能体开发平台的框架层（社区版），基于 Java 17 与响应式编程，提供 Agent 运行时、记忆、安全护栏、知识检索、工作流、评测等框架能力。引擎层见 [yangqiong-agent-harness](https://github.com/yangqiongai/yangqiong-agent-harness)（Apache-2.0），平台层（多租户管理后台服务端）见 yangqiong-ai-platform。

## 构建

```bash
mvn -DskipTests package
```

详细指南与示例见官网 <https://yangqiongai.com>。
