# 泱穹智能体平台业务能力层（yangqiong-ai-platform）

泱穹智能体平台的平台层（社区版），提供管理后台服务端、用户认证、审计等平台能力，依赖框架层 [yangqiong-ai-framework](../yangqiong-ai-framework)。SSO/LDAP/OIDC、连接器商业提供商等企业能力为商业版（未随社区分发）。

## 构建

```bash
mvn -DskipTests package
```

详细指南与示例见官网 <https://yangqiongai.com>。
