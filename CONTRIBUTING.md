# Contributing to YangQiong AI

Anyone can contribute to the YangQiong AI project and we welcome your contributions.

## How to Contribute

- Raise bug reports or enhancement requests on the respective repository's issue tracker. Please search the existing issues first to avoid duplicates. A good bug report provides as much context as possible so we can reproduce the issue; a good enhancement request explains what you are trying to achieve and how it would help.
- Follow the coding standards used throughout the existing code base. All source files must carry the applicable license header (see LICENSE-HEADER in each repository).
- All pull requests must pass the CI build before they can be merged.

## Contributor License Agreement (CLA)

Before contributing, please read the [Contributor License Agreement (CLA)](./CLA.md).

**By submitting a Contribution to the Project (e.g. via a pull request, patch, issue attachment, or any other channel), you accept the CLA — no separate sign-up is required.** Each pull request you open is treated as confirmation that you have read and agreed to the CLA for that and every future contribution.

For larger or corporate contributions, the Maintainer may ask you to explicitly acknowledge the CLA in writing (for example, by adding a statement to the pull request description) before merging.
